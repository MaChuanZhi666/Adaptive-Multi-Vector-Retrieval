# Adaptive-Multi-Vector-Retrieval

Research on query-adaptive computation for PLAID/ColBERT-style multi-vector retrieval, motivated by retrieval-augmented generation (RAG).

## Project status

See [Research Progress](docs/RESEARCH_PROGRESS.md) for the current scope, completed experiments, preliminary findings, limitations, and next steps. Reported findings are explicitly separated from ongoing work; no learned controller or multi-stage adaptive improvement is claimed yet.

## Full research archive

The repository now contains a curated history of the broader research, not only the current status snapshot. Start with the [research archive](docs/RESEARCH_ARCHIVE.md), which links the benchmark studies, adaptive-search investigations, incremental reuse work, profiling/controller audits, related-paper notes, selected code, aggregate data, figures, and a dated presentation. Raw datasets, private server details, indexes, and large per-query dumps are intentionally excluded from this public repository.
